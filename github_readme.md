# Mimic Studio

> A sleek, single-file Web Audio voice transformer featuring an interactive Claude-inspired mascot avatar and iOS-style gesture recording.

![License](https://img.shields.io/badge/license-MIT-zinc)
![Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20TailwindCSS%20%7C%20Web%20Audio%20API-zinc)

## Features

- **Interactive SVG Mascot:** Audio-reactive Claude-inspired avatar with dynamic lip-syncing and responsive eyes.
- **Apple Slide-to-Lock:** Slide to lock audio recording hands-free.
- **Voice Pitch Engine:** Built-in presets (*Tom, Deep Monster, Robot, Helium, Echo Chamber*) and precise fine-tuning sliders (Pitch, Speed, Echo).
- **Audio Visualizer:** Dual-mode HTML5 Canvas oscilloscope waveform and frequency bar visualizer.
- **Single File Build:** Self-contained single HTML file with no build steps or heavy dependencies.

## Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/mimic-studio.git
   ```
2. Open `index.html` in any modern web browser.
3. Grant microphone permission and start recording!

## Tech Stack

- **UI System:** Tailwind CSS (Shadcn Dark Aesthetic)
- **Audio Processing:** Web Audio API & MediaRecorder API
- **Visualizer:** HTML5 Canvas
- **Icons:** SVG (Lucide-inspired)
